# 🚀 Quick Start Guide - GunGong Browser Extension

เริ่มใช้งาน GunGong Extension ใน 5 นาที!

## ⚡ การติดตั้งด่วน

### ขั้นตอนที่ 1: โหลด Extension (2 นาที)

```bash
# 1. Clone repository
git clone https://github.com/your-repo/gungong-v2.0.git

# 2. เข้าโฟลเดอร์ extension
cd gungong-v2.0/browser-extension
```

### ขั้นตอนที่ 2: ติดตั้งใน Chrome (1 นาที)

1. เปิด Chrome → ไปที่ `chrome://extensions/`
2. เปิด **Developer mode** (สวิตช์มุมขวาบน)
3. คลิก **Load unpacked**
4. เลือกโฟลเดอร์ `browser-extension`
5. ✅ เสร็จแล้ว!

### ขั้นตอนที่ 3: ตั้งค่า Backend API (2 นาที)

1. คลิกขวาที่ไอคอน Extension → **Options**
2. ใส่ URL ของ Backend:
   ```
   http://localhost:8000
   ```
   (หรือ URL ที่ Backend ของคุณรันอยู่)
3. คลิก **🔍 ทดสอบการเชื่อมต่อ**
4. เห็น "✓ เชื่อมต่อสำเร็จ!" → คลิก **💾 บันทึก**

## 🎯 ทดสอบใช้งาน

### ทดสอบที่ 1: ตรวจสอบหมายเลขโทรศัพท์

1. คลิกไอคอน GunGong
2. แท็บ **ตรวจสอบ** → ใส่ `0812345678`
3. คลิก **ตรวจสอบ**
4. ดูผลลัพธ์ ✅

### ทดสอบที่ 2: สแกนหน้าเว็บ

1. เปิดเว็บที่มีหมายเลขโทรศัพท์
2. Extension จะไฮไลท์ข้อมูลอัตโนมัติ
3. คลิกที่ข้อมูลที่ไฮไลท์เพื่อตรวจสอบ

### ทดสอบที่ 3: วิเคราะห์ข้อความ

1. คลิกไอคอน GunGong
2. แท็บ **วิเคราะห์ข้อความ**
3. วางข้อความทดสอบ:
   ```
   ด่วน! โอนเงินภายใน 1 ชั่วโมง รับดอกเบี้ย 50%
   ```
4. คลิก **วิเคราะห์** → ดูระดับความเสี่ยง 🔴

### ทดสอบที่ 4: Context Menu

1. เลือกหมายเลขโทรศัพท์ในหน้าเว็บ
2. คลิกขวา → **GunGong** → **ตรวจสอบข้อมูลที่เลือก**
3. ดูการแจ้งเตือน 🔔

## 🎨 ตัวอย่างการใช้งาน

### กรณีที่ 1: ตรวจสอบโพสต์ขายของ

1. เห็นโพสต์ขายของราคาถูกผิดปกติ
2. Extension ไฮไลท์เบอร์โทรอัตโนมัติ
3. คลิกที่เบอร์ → ตรวจสอบ
4. พบว่าอยู่ในบัญชีดำ → **ไม่ซื้อ!** ⚠️

### กรณีที่ 2: ตรวจสอบข้อความแปลกๆ

1. ได้รับข้อความผ่าน Messenger
2. Copy ข้อความ → เปิด Extension
3. แท็บ "วิเคราะห์ข้อความ" → Paste
4. AI วิเคราะห์ว่าเป็นข้อความฉ้อโกง → **ระวัง!** 🚨

### กรณีที่ 3: ตรวจสอบเว็บไซต์

1. เปิดเว็บไซต์ที่น่าสงสัย
2. คลิกขวา → GunGong → **สแกนหน้านี้**
3. Extension สแกนหาเบอร์และบัญชีทั้งหมด
4. แสดงผลการตรวจสอบทุกข้อมูล

## 🔧 การแก้ปัญหาเบื้องต้น

### ปัญหา: ไม่สามารถเชื่อมต่อ API

**วิธีแก้:**
```bash
# 1. ตรวจสอบ Backend รันอยู่หรือไม่
curl http://localhost:8000/health

# 2. ถ้ารัน Backend ด้วย Docker
docker ps  # ดูว่า container รันอยู่

# 3. ถ้ารัน Backend ด้วย uvicorn
cd src/backend
uvicorn main:app --reload
```

### ปัญหา: Extension ไม่ทำงาน

**วิธีแก้:**
1. รีโหลด Extension: `chrome://extensions/` → คลิก 🔄
2. รีเฟรชหน้าเว็บ: กด F5
3. เช็ค Console: F12 → ดู error

### ปัญหา: ไม่เห็นการไฮไลท์

**วิธีแก้:**
1. ไปที่ Options → เปิด "ไฮไลท์ข้อมูล"
2. รีเฟรชหน้าเว็บ
3. ตรวจสอบว่าหน้าเว็บมีข้อมูลที่ตรวจจับได้

## 📱 แป้นพิมพ์ลัด (Keyboard Shortcuts)

ยังไม่ได้ตั้งค่า - สามารถเพิ่มได้ที่ `chrome://extensions/shortcuts`

**แนะนำ:**
- `Alt+G` - เปิด popup
- `Ctrl+Shift+G` - สแกนหน้าเว็บ
- `Ctrl+Alt+G` - ตรวจสอบข้อความที่เลือก
