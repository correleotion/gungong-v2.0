⚙️ ตั้งค่า GunGong Extension

กำหนดค่าการทำงานของ extension

🔗 การเชื่อมต่อ API

URL ของ GunGong Backend API (ค่าเริ่มต้น: http://localhost:8000)

🔍 การสแกน

สแกนหาหมายเลขโทรศัพท์และบัญชีธนาคารเมื่อเปิดหน้าเว็บ
ตรวจสอบข้อมูลที่พบกับ blacklist โดยอัตโนมัติ
แสดงเส้นใต้และสีพื้นหลังสำหรับข้อมูลที่ตรวจพบ

🔔 การแจ้งเตือน

แสดงการแจ้งเตือนเมื่อพบข้อมูลที่เสี่ยงหรือมีในบัญชีดำ
แจ้งเตือนเฉพาะเมื่อพบข้อมูลในบัญชีดำหรือความเสี่ยงสูง

🔒 ความเป็นส่วนตัว

เก็บประวัติการตรวจสอบในเครื่องของคุณ (ไม่ส่งไปยังเซิร์ฟเวอร์)
ลบประวัติการตรวจสอบทั้งหมดที่เก็บไว้ในเครื่อง
ล้างข้อมูล cache ทั้งหมดของ extension

ℹ️ เกี่ยวกับ

GunGong - ตรวจสอบการฉ้อโกง

เวอร์ชัน: 1.0.0

Browser Extension สำหรับตรวจสอบหมายเลขโทรศัพท์ บัญชีธนาคาร และวิเคราะห์ความเสี่ยงจากข้อความด้วย AI
